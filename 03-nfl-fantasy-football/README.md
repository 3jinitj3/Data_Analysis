# 🏈 NFL Fantasy Football — Historical Stats Scraper (In Progress)

This project aims to build a **Python‑based data extraction tool** for scraping **historical NFL player statistics** to support long‑term analysis for **fantasy football strategy, projections, and modeling**.  

It represents a hands‑on effort to apply data skills learned at DataCamp while reverse‑engineering advanced scraping logic from an established open‑source project.

## 🎯 Project Goals

### **1. Scrape Historical NFL Data**
- Player statistics (passing, rushing, receiving)
- Team‑level performance
- Weekly and seasonal historical breakdowns

### **2. Build a Reusable Scraping/Parsing Engine**
- Requests‑based HTML retrieval  
- BeautifulSoup parsing (planned)  
- Modular year‑loop scraping functions  
- Resilient error handling and cleaner architecture

### **3. Clean and Structure Data**
- Convert HTML tables into clean DataFrames  
- Normalize inconsistent names or field formats  
- Combine multiple years into unified datasets  
- Export in CSV/parquet for future modeling

### **4. Support Fantasy Football Analytics**
- Player trend evaluation  
- Breakout candidate analysis  
- Weekly prediction tooling  
- Historical fantasy scoring metrics (PPR, half‑PPR, standard)
